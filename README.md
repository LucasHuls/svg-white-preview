# SVG White Preview

Opens `.svg` files on a white background by default, so line drawings stay visible in a dark theme.

- Click an `.svg` file: it opens in this preview, fitted to the window.
- Toolbar button (color mode icon): cycle background white / dark / checkerboard. The choice is saved globally.
- Toolbar button (zoom icon): toggle between fit-to-window and 100%.
- The preview reloads automatically when the file changes on disk.
- Use **Open With...** on the file to get the text editor or the built-in image preview instead.

## Setting

`svgWhitePreview.background`: `white` (default), `dark` or `checkerboard`.
